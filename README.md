# 🌐 Portfólio Pessoal - Lucas Guidi

Bem-vindo ao repositório do meu portfólio web! Este projeto foi desenvolvido para apresentar minha trajetória, competências técnicas, principais projetos acadêmicos/pessoais e meios de contato, utilizando uma interface moderna, intuitiva e responsiva.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de todo o conteúdo web.
- **CSS3:** Estilização personalizada, paleta dark mode elegante, layout com Flexbox/Grid e animações de transição.
- **JavaScript (ES6+):** Manipulação de elementos interativos, como navegação e efeito de digitação dinâmica (*typing effect*).
- **Ionicons / DevIcons:** Ícones vetoriais integrados para representação visual das tecnologias.

---

## 🎯 Seções do Site

- **Início (Hero Section):** Apresentação principal com chamada para ação (*Download CV*).
- **Sobre Mim:** Breve resumo da minha trajetória profissional e paixão pelo desenvolvimento de software.
- **Hard Skills:** Cards detalhados com as principais tecnologias e ferramentas dominadas (C#, Web Design, MySQL, Python, Hardware, Office 365).
- **Especialidades:** Barras de progresso visual demonstrando nível de afinidade e prática em cada linguagem/ferramenta.
- **Projetos:** Carrossel/Cards demonstrando projetos em destaques (como *GuidiBank* e *MainPlace*).
- **Contato:** Links diretos para redes sociais e formas de comunicação.
